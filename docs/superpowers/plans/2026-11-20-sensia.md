# SenSia Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun pipeline analisis sentimen saham Indonesia end-to-end — dataset berlabel dari X/Threads, model Bi-LSTM 3 kelas, dan web app Flask — yang bisa dijalankan ulang dari repo GitHub.

**Architecture:** Kontrak data (label, konstanta, cleaning, validator) hidup di paket `sensia/` yang diimpor notebook *dan* web app, supaya tidak ada perbedaan perlakuan teks antara training dan prediksi. Notebook memuat seluruh pipeline dan menyimpan tiga artefak ke `model/`; Flask hanya memuat artefak itu dan memvalidasi input.

**Tech Stack:** Python 3.11/3.12, TensorFlow 2.x (Keras), pandas, scikit-learn, matplotlib, openpyxl, Flask, pytest, nbconvert. Tanpa database, tanpa API pihak ketiga.

**Spec:** `docs/superpowers/specs/2026-11-20-sensia-design.md`

## Global Constraints

- Python 3.11 atau 3.12 di dalam virtualenv. Tidak butuh GPU, tidak butuh lerd/Podman.
- `SEED = 42` dipakai untuk split dan training.
- `VOCAB_SIZE = 10000`, `MAX_LEN = 100`, embedding 128, Bi-LSTM 64, dropout 0.3, batch 32, max 15 epoch.
- `LABELS = ["negatif", "netral", "positif"]` — urutan ini **mengikat**; indeks 0/1/2 di output softmax adalah urutan ini.
- Target dataset: 900 baris, 300 ± 20 per kelas.
- Ambang kelulusan: test accuracy ≥ 0.75 **dan** macro F1 ≥ 0.70.
- Artefak model: `model/sensia_bilstm.keras`, `model/tokenizer.json`, `model/label_map.json`. Ketiganya **di-commit**.
- Teks mentah disimpan apa adanya di dataset; semua cleaning dijalankan kode, tidak pernah diedit di spreadsheet.
- Tanpa API X/Threads, tanpa crawling skala besar, tanpa menyimpan username/handle/foto.
- `POST /predict` menerima `{"text": str}` dan mengembalikan `{"label": str, "confidence": float, "scores": {negatif,netral,positif}}`; error selalu `400 {"error": str}`.
- Batas input web app: 3–500 karakter, dan teks yang bersih-nya kosong ditolak.

## Review Focus

Hal-hal yang tidak diuji langsung oleh pipeline normal tapi paling mungkin merusak demo:

1. **Teks yang setelah cleaning jadi kosong** (hanya emoji, URL, mention) — harus ditolak dengan pesan, bukan menghasilkan prediksi acak atau crash.
2. **Input 500 karakter** — harus terpotong ke 100 token tanpa error; 501 karakter harus ditolak server.
3. **Urutan label** — notebook dan web app harus memakai `LABELS` yang sama; salah urutan membalik prediksi tanpa error apa pun.
4. **Teks duplikat/repost** yang jatuh di train dan test sekaligus — membesarkan akurasi secara palsu.
5. **File model hilang** setelah clone (mis. tidak sengaja di-gitignore) — harus muncul pesan yang menyebut notebook, bukan traceback Keras.

```python
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Embedding, Bidirectional, LSTM, Dense, Dropout

model = Sequential([
```

```python
                        maxlen=MAX_LEN, padding="post", truncating="post")
    p = model.predict(seq, verbose=0)[0]
    return {"label": LABELS[int(p.argmax())], "confidence": float(p.max()),
            "scores": {l: round(float(x), 4) for l, x in zip(LABELS, p)}}

for s in ["ihsg anjlok parah, kapok main saham", "waktunya beli, bbca murah banget", "ihsg ditutup di 6812"]:
    print(s, "->", prediksi(s))
```
